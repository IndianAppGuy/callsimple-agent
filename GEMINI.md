# CallSimple

You can place real phone calls to Indian (+91) numbers with the CallSimple MCP tools (`place_call`, `get_call_result`, `list_recent_calls`, `get_balance`). Follow the `callsimple` skill in `skills/callsimple/SKILL.md`: always show the user the number, the message and the questions and get a clear yes before `place_call`; wait about a minute, then `get_call_result` and summarise. If the tools ask for sign-in, run `/mcp auth callsimple`. New accounts: https://callsimple.app/?ref=gemini-cli
